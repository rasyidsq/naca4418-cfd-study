# CFD Analysis of NACA 4418 Airfoil in Two-Phase Air-Sand Flow

## 📌 Project Overview
This study investigates the aerodynamic performance degradation of NACA 4418 airfoil under two-phase (air-sand) flow conditions using Computational Fluid Dynamics (CFD) simulation in ANSYS Fluent. The research aims to analyze the impact of environmental sand particles on wind turbine efficiency.

## 🛠️ Tools & Software
- ANSYS Fluent 2024 R2
- SST k-omega turbulence model
- Discrete Phase Model (DPM)
- 2D Transient Simulation

## 📊 Key Findings
- **At 6 m/s**: Drag increased by **74%**, aerodynamic efficiency decreased by **43%** in two-phase flow.
- **At 10 m/s**: Lift increased slightly, efficiency improved by **0.7%** due to flow stabilization.
- Sand particles increase turbulence kinetic energy at the trailing edge.
